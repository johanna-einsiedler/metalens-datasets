# Claims in Danish register-data economics papers

The claims stated in the abstracts of 244 economics papers that use Danish register data, each linked to the regression estimates that test it, grouped into estimands with one main estimate each. Imported from run 1 of the danish-register-econ agent pipeline (Claude Opus 5; protocols stated claims v2 and claim map v1). The Danish Causal Atlas draws the edge claims of this corpus as one graph.
